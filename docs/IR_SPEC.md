# CodingFly IR v0.1

이 규격은 학습 자료·체크포인트·평가에서 SHA-256으로 고정한다. 검증기는 형식만 검사하며 Python으로 번역하거나 누락된 의미를 채우지 않는다.

UTF-8, 한 줄에 한 명령. 공백/들여쓰기는 구분용이다. 빈 줄은 무시한다. 주석은 없다. 최대 8,192바이트, 256줄, 블록/표현식 깊이 32. 모든 블록은 명시적으로 닫는다.

| 명령 | 형식과 의미 |
| --- | --- |
| FUNC | `FUNC 이름 [매개변수 ...]`: 최상위 함수, `END_FUNC`로 종료 |
| LET | `LET 이름 식`: 현재 함수 또는 최상위 변수에 대입 |
| PRINT | `PRINT 식`: 값 하나와 개행 출력 |
| ADD | `ADD 이름 식`: 기존 변수에 더해 대입 |
| IF | `IF 식`: 참인 경우 실행, `END`로 종료 |
| ELSE | 인자 없음. 바로 둘러싼 IF의 대안, 한 번만 허용 |
| FOR | `FOR 이름 RANGE 시작 끝`: 시작 포함, 끝 제외, 간격 +1 |
| RETURN | `RETURN 식`: 함수 내부에서 반환 |
| CALL | `CALL 함수 [식 ...]`: 호출하고 결과를 버림 |
| END | IF 또는 FOR 종료 |
| END_FUNC | FUNC 종료 |

식은 정수(음수 허용, 최대 64문자), JSON 큰따옴표 문자열, 식별자, `TRUE`, `FALSE`, 또는 괄호로 둘러싼 전위식이다. 식별자는 Python의 `isidentifier()`를 만족하며 Python 키워드와 IR 예약어는 금지한다. 이항 연산은 `(ADD a b)`, `SUB`, `MUL`, `DIV`(Python `/` 의미), `MOD`, `EQ`, `NE`, `LT`, `LE`, `GT`, `GE`, `AND`, `OR`. 단항은 `(NOT 식)`, `(NEG 식)`. `(LIST 식 ...)`는 목록, `(CALL 함수 식 ...)`는 반환값이다. 괄호가 우선순위를 모두 명시한다. 목록 인덱싱·부동소수·가변 간격은 v0.1 범위 밖이다.

변수는 현재 함수/최상위 범위를 사용한다. 정의되지 않은 이름, 잘못된 피연산자 타입 등은 의미/실행 오류다. 형식 검사기가 값을 추론하지 않는다. RETURN과 PRINT는 대체할 수 없다.

```
FUNC sum_even
LET total 0
FOR i RANGE 1 11
IF (EQ (MOD i 2) 0)
ADD total i
END
END
RETURN total
END_FUNC
```

COPY는 IR 명령이 아니라 **신경 출력 전송 동작**이다. `COPY(start,end)`는 원본 UTF-8 바이트의 반열린 구간만 그대로 출력한다. 구간 선택은 모델이 한다. 범위를 벗어나거나 UTF-8이 깨지면 실패한다. 초기 Fly-Code 실험은 공백으로 나눈 원문 span 목록을 고정하고 `COPY(index)`로 해당 구간을 선택한다. 어휘 의미나 명령별 인자 추출은 하지 않는다. 향후 임의 바이트 구간 포인터와 호환되는 제한된 표현이다.

생성 프로토콜의 BOS/EOS는 원문에 쓰지 않는 제어 토큰이다. 최대 출력 동작 수/시간 제한에 도달하면 `max_tokens`/`timeout` 실패로 남긴다. EOS를 자동 추가하지 않는다. Python 공백·개행도 출력 동작이다. 검증기는 자동 완성·자동 수정하지 않는다.
