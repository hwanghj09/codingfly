# P6: 실패 피드백과 제한된 재시도

`models/retry.py`는 첫 생성 이후 최대 두 번 더 시도한다. 기본 CLI는 기존처럼 단회 생성이다. 재시도는 사용자 제공 테스트가 있어야 하며, 코드·IR을 자동 교정하거나 외부 모델을 호출하지 않는다.

```bash
# v2 문서의 두 모델 학습을 먼저 실행한다.
python -m evaluation.retries --output artifacts/retry-v1
python -m evaluation.snapshot_retry --study artifacts/retry-v1
python dual_fly.py --goal '변수 "total" 에 7 를 저장해' \
  --nl-dir artifacts/nl-v2 --tests oracle.json --max-attempts 3 --feedback-mode weak
```

위 CLI의 `oracle.json`:

```json
{"stdout":"","variables":{"total":7}}
```

`--trace`를 추가하면 실패 입력의 해시, 실제 readout 확률, 선택한 동작 및 후보 순위를 볼 수 있다. `retry.attempts`는 각 시도의 IR·Python·검사 결과·보상·피드백·추적 ID를 보존한다. 성공, 불확실 응답, 격리 인프라 오류에서는 바로 종료한다. 실패한 마지막 결과를 성공으로 바꾸거나 이전 코드를 재작성하지 않는다.

## 선택과 피드백

첫 시도는 피드백 없는 기존 greedy 생성과 같다. A의 재시도에서는 신경망이 계산한 문맥 점수의 다음 순위 후보를 탐색하고, 포인터와 IR 토큰은 해당 후보 아래에서 신경망이 생성한다. B에 책임이 있는 재시도에서는 신경 readout의 digit 확률을 temperature 0.3으로 표본화한다. 고정 시드로 재현되며, 출력·실행 정답을 보고 토큰을 고르는 코드는 없다.

실패 피드백은 보상, 오류 단계, 검사 종류, 실패한 함수 입력과 실제 관측값으로 구성된다. 기대 출력·정답 반환값·정답 IR은 신경망에 전달하지 않는다. 앞선 신경 동작의 최근 128개와 생성물 해시도 전달한다. 고정 크기 바이트 해시를 기존 input 뉴런에 강도 0.01로 더하며, readout 뉴런은 직접 자극하지 않는다. 기존 체크포인트와 첫 시도의 입출력 부호화는 유지한다. 이 추가 채널은 피드백 데이터로 훈련한 채널이 아니므로 유용성을 별도로 측정해야 한다.

| 모드 | 전달하는 정보 | 책임과 재생성 |
| --- | --- | --- |
| `resample` | 피드백 없음 | 동일 최대 시도 예산의 탐색 대조군 |
| `weak` | 실패 보상과 앞선 동작·생성물 해시 | 의미 오류 책임은 미분리; A와 B 재생성 |
| `supervised` | 구체적 실패 검사와 단계 정보 | A 오류이면 A 재생성 후 B 번역; B 로컬 오류이면 A 결과 재사용 |

일반 CLI의 `supervised` 모드는 IR 형식·B 생성·Python 문법 같은 로컬 오류를 구분한다. 정답 IR이 없으면 실행 결과 오류의 의미 책임은 `unlocalized`다. 평가 전용 감독자는 정답 IR을 비교해 A의 의미 오류와 B의 로컬 오류를 분리한다. 정답 IR은 책임 분류에만 사용하고, 생성 함수·출력 선택·종료 판단에는 전달하지 않는다. 이 감독 조건의 결과를 정답 IR 없는 CLI 성능으로 해석하면 안 된다.

## 비교 조건과 해석

평가는 기존 v2의 공개된 test 표현 36개와 같은 표현에 새로운 이름·상수를 적용한 36개를 사용한다. 각 코호트는 지원 요청 32개와 미지원 요청 4개다. **새로운 숨긴 언어 표현 평가가 아니다.** 원본 v2 hidden study를 재학습하거나 재채점해 덮어쓰지 않는다. 별도 버전의 데이터·프로토콜·모델 해시를 실행 전에 잠그며, 이미 연 retry study는 덮어쓰지 않는다.

세 모드에 최대 3회와 디코딩 시드 0~4를 동일하게 적용한다. 첫 시도 결과는 같으며, 성공 시 종료하므로 실제 평균 시도 수는 다를 수 있다. 함수의 첫 공개 호출만 재시도 선택에 사용하고, 전체 경계 호출은 최종 선택 후 별도 채점한다. 대입·출력 과제는 고정 요청의 관측값이므로 독립적인 숨긴 입력이 없다는 한계가 있다. 실행은 기존 OS 격리 채점기를 사용한다.

모든 비교에서 A/B 가중치를 고정하고 업데이트 수 0과 전후 해시를 기록한다. 시드 5개는 **검색 난수 시드**이며 독립 학습 시드가 아니다. 재시도 뒤 정답률은 `selected_pass_within_3`로 보고하며 고전적인 무조건 표본 Pass@3와 구분한다. 학습 향상과도 구분한다. 피드백의 추가 효과는 동일 예산의 `resample` 대비로 판단한다.

실측 결과는 [현재 결과](IMPLEMENTATION_RESULTS.md)와 [P6 JSON 보고서](reports/retry-v1.json)에 기록한다. 전체 시도와 뉴런 trace는 `artifacts/retry-v1/report.json`에 보존한다. 이 단계는 고정 가중치 재시도 프로토타입이다. 실패 보상으로 시냅스를 재학습하는 후속 연구, P7의 전체 언어 대조, P8 대시보드는 남아 있다. 피드백 바이트가 의미적으로 이해되었다는 주장은 하지 않는다. 무작위 또는 뒤섞인 피드백을 넣는 추가 대조 없이, 작은 고정 입력 섭동의 효과와 의미 정보의 효과를 구분할 수 없다.
