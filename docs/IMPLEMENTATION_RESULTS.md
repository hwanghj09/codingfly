## P6: 최대 3회 재시도 실측 — 2026-11-12

| 동일 지원 요청 64개 | 실행 정답 | 정답률 |
| --- | ---: | ---: |
| 단회 생성 | 48/64 | 75% |
| 피드백 없는 탐색, 최대 3회 | 56/64 | 87.5% |
| 약한 실패 피드백, 최대 3회 | 59/64 | 92.1875% |
| 단계별 감독 피드백, 최대 3회 | 62/64 | 96.875% |

각 조건의 디코딩 시드 0~4에서 같은 점수였다. 미지원 요청을 포함한 72개 요청당 평균 시도는 1.444회이고, 각 조건의 미지원 요청 8개는 모두 불확실 응답이었다. 총 1,080회 요청 실행의 원본 시도·trace를 남겼다. A/B 체크포인트와 가중치는 모두 고정했고 학습 업데이트는 0이다. 신경망 점수의 다음 문맥 후보를 탐색하며, 실패 바이트와 이전 동작을 기존 input 뉴런에 추가한다. 수정 IR·Python을 사람이 작성한 코드로 대체하지 않는다.

기존 v2 test 32개와 같은 표현의 새 이름·상수 요청 32개를 묶은 **이미 공개된 표현의 재시도 진단**이다. 새 숨긴 문장 성능으로 해석하지 않는다. 함수는 첫 공개 호출로 재시도 종료를 판단하고, 전체 경계 호출은 최종 선택 후 검사했다. 고정 대입·출력 과제에는 독립 숨긴 실행 입력이 없다. 원본 v2 평가·체크포인트는 덮어쓰거나 재학습하지 않았다.

단계별 감독자는 정답 IR을 **오류 책임 분류**에만 사용하며, 정답 IR·기대 출력·정답 반환값은 생성 함수에 전달하지 않는다. 일반 CLI는 정답 IR 없이 로컬 오류만 분류하므로 이 감독 조건의 점수를 그대로 적용할 수 없다. 시드 5개는 같은 학습 체크포인트의 검색 시드다. 표준편차가 0이어도 독립 학습의 불확실성이나 범용 정확성이 사라졌다는 뜻은 아니다.

단회 대비 상승의 상당 부분은 탐색만으로 얻었다. 약한 피드백이 추가로 3개, 감독 피드백이 6개를 맞혔지만, 훈련되지 않은 추가 입력 채널의 작은 섭동과 의미 정보의 효과를 구분하는 뒤섞인 피드백 대조는 아직 없다. 학습 향상이나 피드백 의미 이해를 주장하지 않는다. 약한 피드백의 최종 실패는 대입 의도 5개, 감독 조건은 2개이며, 모두 불확실 응답으로 끝났다.

전체 테스트는 **92개** 통과했고 기존 benchmark 네 결과 행도 유지됐다. CLI에서 `변수 "total" 에 7 를 저장해`의 불필요한 PRINT가 세 번째 신경 생성에서 사라져 공개 오라클을 통과했다. [P6 구조·실행 방법](DUAL_FLY_P6.md) · [비교 JSON·실패·뉴런 근거](reports/retry-v1.json) · [회귀·CLI 검증 기록](reports/verification-p6.json)

## 무엇을 고쳤는가

v1은 변수 이름 길이가 바뀌면 출력 접두사의 위치가 흔들렸고, 연결 수가 부족한 출력 뉴런도 어휘 선택에 사용했다. v2는 IR 문법 토큰을 고정 ID로, 값·이름을 불투명 COPY 후보로 부호화한다. 연결이 많은 두 readout 뉴런을 이진 시간 슬롯으로 읽으며, 다음 줄 이동·들여쓰기·블록 변경도 신경 출력으로 선택한다.

원본 간선 전용 희소 배치 BPTT와 Adam 이후 bounded L-BFGS-B를 적용했다. v2는 간선 강도의 부호 변경을 허용하는 인공 학습 가정을 사용한다. 실제 신경전달물질 정보를 반영한 학습법이라는 주장은 하지 않는다.

A는 의도 문맥과 원문 포인터를 신경 점수로 선택하고, 같은 그래프가 임시 레지스터를 참조해 IR 바이트를 생성한다. 문맥 ID를 완성 IR로 치환하는 외부 템플릿은 없다. B 역시 각 Python 리터럴·COPY·블록 제어를 신경 활동에서 선택한다. 외부 모델·legacy 번역기·teacher 모듈은 생성 경로에서 차단한다.

## 재현 조건과 데이터

- B: 2,048개 뉴런, 5,340개 원본 간선, 시드 0. 24종 제한된 프로그램 유형을 이름/수치 그룹으로 384/96/96 분리했다. 60 epoch Adam 이후 최대 160회 L-BFGS-B 중 98회에서 수렴했다.
- A: 독립 시냅스와 시드 101. 한국어 8종 과제와 불확실 응답을 576/36/36으로 분리했다. train 표현 0~3, validation 표현 4, test 표현 5 및 이름 그룹이 서로 겹치지 않는다. 60 epoch 이후 L-BFGS-B 67회에서 수렴했다.
- 생성기를 선택할 때는 validation을 사용하고, test는 선택 후 한 번 열었다. 열린 study는 재학습·추가 최적화·재채점을 막는다. 종단 진단에서도 모델 가중치는 변경되지 않았다.
- 학습 자극의 정확 중복을 제거한 고유 상태는 B 1,818개, A 2,000개다. 이는 고정 I/O 상태의 중복 제거이며 생성 시 정답 조회에 사용하지 않는다.
- 기존 legacy 테스트 19개와 benchmark의 4개 결과 행은 유지했다. P5까지 80개 테스트였고, P6 추가 후 전체 회귀·신경·프로토콜·격리 검증은 92개다.

함수는 단일 정답 숫자 대신 여러 인자·음수·0·경계 입력에서 실행한다. 생성 코드는 읽기 전용·네트워크 격리·자원 제한이 있는 별도 OS namespace에서 채점한다. 오라클이 없는 CLI 출력은 의미 검증을 통과했다고 표시하지 않는다.

## 남아 있는 실제 오류

지원 요청의 실패 8개는 두 표현 유형에서 발생했다. “변수에 값을 저장해”라는 새 표현에 불필요한 PRINT를 붙이거나, “저장한 뒤 더해서 출력해”에서 ADD와 PRINT를 누락했다. 정답 IR을 B에 주면 모두 통과하므로 현재 종단 병목은 A의 의미 선택이다. 검사기가 오답 IR이나 Python을 교정하지 않고 결과에 그대로 남겼다.

B의 별도 조합 평가에서는 새로운 비교 연산·중첩 깊이 조합 하나가 실패했다. 24종 결과는 제한된 문법/패턴과 새 인자에 대한 평가다. 임의 알고리즘 계열·영어·붙여 쓴 숫자/조사·자유로운 복합 지시의 정확성을 입증하지 않는다. 현재 식별자는 큰따옴표로, 숫자와 조사는 공백으로 구분한다.

현재 signed-edge toy task의 5시드 평균은 학습 99.44%, frozen 27.22%, degree-preserving 재연결 100%, 무작위 그래프 96.67%다. 이 결과로 실제 FlyWire 배선의 우월성을 주장할 수 없다. 전체 언어 모델의 다중 시드·한 파리/두 파리·알고리즘 계열 대조는 아직 남아 있다.
