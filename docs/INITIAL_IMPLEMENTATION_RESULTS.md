## P2 — 실제 시냅스 학습

64개 실제 뉴런, 168개 방향성 간선, 첫 바이트의 4분류 toy task. 훈련 120개, validation/test 각 36개이며 두 번째 바이트 그룹이 겹치지 않는다. 30 epoch, 학습률 .03, 시드 0~4를 고정했다.

| 조건 | test 평균 | 표본 표준편차 |
| --- | ---: | ---: |
| 실제 배선 + 학습 | 91.67% | 5.89% |
| 실제 배선 + frozen | 23.89% | 11.21% |
| degree-preserving 재연결 + 학습 | 88.33% | 8.43% |
| 무작위 그래프 + 학습 | 88.89% | 6.51% |
| 실제 배선 + 억제성 20% 가정 + 학습 | 96.11% | 3.17% |

5개 시드의 학습 모델은 각각 86.11%, 100%, 86.11%, 94.44%, 91.67%였다. 모든 시드에서 frozen보다 개선됐다. 원본 168개 간선 중 163개 강도가 변경됐고 frozen은 변경 0개였다. 모든 저장·복원 추론이 정확히 일치했고, 전달을 끄면 25%로 돌아갔다. 따라서 **작은 바이트 과제의 시냅스 학습 가능성**은 확인했다.

무작위/재연결 대조군도 비슷한 수준이고, 흥분/억제 부호 가정의 영향도 크다. **FlyWire 배선이 더 우수하거나 언어를 이해한다는 결론은 내릴 수 없다.** [P2 결과 JSON](reports/toy-p2.json)

## P3 — Fly-Code 초기 실험

2,048개 뉴런, 5,340개 원본 간선, 출력 뉴런 23개. LET/PRINT 및 두 명령 조합만 사용한다. 훈련 72개, validation/test 각 24개이며 변수·상수 묶음은 겹치지 않는다. 시드 0, 40 epoch, 학습률 .03, 최대 출력 32동작을 고정했다.

| 조건 | 마지막 훈련 teacher 동작 정확도 | hidden 문법 | 문법 통과 중 실행 정답 | hidden Pass@1 |
| --- | ---: | ---: | ---: | ---: |
| 학습 | 79.0% | 8/24 (33.3%) | 2/8 (25.0%) | 2/24 (8.3%) |
| frozen | 3.5% | 0/24 | 0 | 0/24 |

**로드맵의 문법≥90%·실행 정답≥80% 목표를 달성하지 못했다.** IF/FOR/FUNC 확장, Fly-NL, 두 파리 통합도 아직 완료되지 않았다. 24개 프로그램은 세 형태의 변수·상수 변형이므로 24개 알고리즘 유형으로 세지 않는다. 성공한 두 출력만 골라 범용 코딩 능력으로 보고하지 않는다. [P3 결과·실패 사례 JSON](reports/fly-code-p3.json)

실패 관찰:

- 정답 접두사를 제공할 때보다 자기 출력으로 계속 생성할 때 정확도가 크게 낮다. `value_10== 19`처럼 첫 잘못된 문자가 접두사를 바꾸면 뒤의 개행/괄호/EOS도 무너진다.
- `print19(19)(`처럼 문법 오류를 내거나 32동작 동안 EOS를 내지 못한 출력이 발생했다. 검사기가 고치지 않고 그대로 실패로 남긴다.
- 변수/숫자 복사를 고를 원문 span 위치도 모델이 예측한다. 존재하지 않는 COPY 위치를 선택하면 `invalid_copy`로 끝낸다.
- 토큰마다 상태를 초기화하고 위치별 바이트 자극을 다시 넣으므로, 현재 모델은 길이/접두사 변화에 강한 장기 문맥을 아직 학습하지 못했다. 이것은 관찰에 근거한 병목 가설이며 원인별 실험은 추가로 필요하다.

다음 개발은 기존 hidden 세트를 튜닝에 재사용하지 않고, 별도 train/validation 실험으로 고정 부호화의 문맥 보존과 순차 학습을 개선하는 것이다. 이후 새로운 잠긴 평가 버전에서 Fly-Code 목표를 검증해야 한다. 신경 외부 번역기를 추가해 점수를 높이는 것은 다음 단계 완료로 인정하지 않는다.

현재 체크포인트/전체 trace/run 보고서는 로컬 `artifacts/`에 저장하며 Git에는 작은 결과 요약과 잠긴 데이터만 포함한다. 동일 명령으로 학습 가중치와 결과를 다시 만들 수 있다. 기존 FlyWire 출처·CC BY-NC 4.0 고지는 [README](../README.md#데이터-출처)에 유지한다.
