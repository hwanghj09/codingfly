Fly-Code의 별도 P3 평가에서는 24종 96개 프로그램이 실행 정답이었고, 미학습 조합·경계 과제는 3/4개를 통과했습니다. [v2 구조·역사적 재현 절차](docs/DUAL_FLY_V2.md)와 기존 결과는 보존합니다.

v2 모델의 [P6 재시도 진단](docs/DUAL_FLY_P6.md)은 이미 공개된 표현 64개에서 단회 48/64, 탐색만 56/64, 약한 피드백 59/64, 단계별 감독 62/64였습니다. 이는 새 v3 단회 평가와 다른 자료·모델의 기록입니다. 감독 조건은 정답 IR을 책임 분류에 사용한 별도 실험입니다.

두 모델은 각각 원본 FlyWire 간선의 강도만 학습하는 독립적인 rate 신경 모델입니다. 출력 뉴런이 의도 문맥, 인자 복사 위치, IR/Python 토큰, 줄 이동과 블록 상태를 선택합니다. 외부 LLM·정규식 의도 분류·코드 템플릿으로 답을 보정하지 않습니다. 고정 입출력 부호화와 임시 레지스터를 사용하는 인공 계산 모델이며, 생물학적으로 검증된 초파리 뇌 시뮬레이터는 아닙니다.

```bash
python -m pip install -r requirements.txt
python -m unittest -v
python benchmark.py
python -m evaluation.toy --free-signs --output artifacts/toy-signed
OPENBLAS_NUM_THREADS=1 python -m models.train_sequence --output artifacts/code-v2 --epochs 60 --polish-steps 160 --evaluate-test
OPENBLAS_NUM_THREADS=1 python -m models.train_nl --output artifacts/nl-v2 --epochs 60 --polish-steps 160 --evaluate-test
OPENBLAS_NUM_THREADS=1 python -m models.train_nl_v3 --output artifacts/nl-v3 --epochs 20 --polish-steps 160
python -m evaluation.accuracy_v3 --output artifacts/nl-v3
python dual_fly.py --ir "PRINT 37"
python dual_fly.py --goal '37 을 출력해'
python dual_fly.py --goal '"count" 에 7 을 저장하고 "count" 를 출력해'
```

새 신경 엔진은 Python 3.10 이상, NumPy, SciPy를 사용합니다. 위 재현 명령은 Linux 기준이며, **실행 채점**에는 `bubblewrap`과 `/usr/bin/python3`가 필요합니다. 격리 불가 환경에서는 `sandbox_unavailable`로 실패하고 호스트 실행으로 대체하지 않습니다. 기존 데모는 계속 표준 라이브러리만 사용합니다. 체크포인트는 명령 실행 시 `artifacts/`에 생성합니다.

현재 자연어 범위는 정수·문자열 출력, 변수 대입·출력, 더한 뒤 출력, 항등/덧셈 함수, 끝을 제외한 정수 구간 출력입니다. **식별자는 큰따옴표로 감싸고 수치·조사는 공백으로 구분**합니다. 영어, 붙여 쓴 수치·조사, 순서가 의미를 바꾸는 임의의 복합 요구는 아직 검증 범위 밖입니다. v2 문장은 v3의 공개 학습 자료이므로 기존 32개를 모두 맞힌 것은 회귀 점수입니다. 실패 보상에 의한 시냅스 재학습, 전체 언어 대조 실험(P7), 새 대시보드(P8)는 남아 있습니다.

`--trace`는 각 선택의 뉴런/가중치 근거를, `--tests oracle.json`은 격리 실행 채점을 제공합니다. 오라클 없이 자연어를 생성하면 `syntax_only`로 표시합니다. 숨긴 평가를 연 run은 재학습·재채점을 막으며, 후속 모델 개발에는 새 평가 버전을 사용합니다. v1 신경 실험은 `--engine v1`과 기존 체크포인트로 재현할 수 있습니다.

v2 자연어 모델은 `--nl-dir artifacts/nl-v2`로 지정합니다. `--engine v2`는 추론 엔진 버전으로, 새 v3 학습 체크포인트도 같은 엔진을 사용합니다.

`--max-attempts 3 --tests oracle.json`은 실패 시 최대 두 번 더 신경 생성을 수행합니다. 기본은 1회이며, 성공·불확실 응답·격리 인프라 오류에서 즉시 종료합니다. [P6 문서](docs/DUAL_FLY_P6.md)에 오라클 예제, 피드백 모드, 한계와 재현 명령이 있습니다.

### 목적에 맞는 코드 작성과 채점

대시보드의 **목적에 맞는 Python 작성**에서 `두 변수 a,b를 각각 1, 3으로 지정해`, `1부터 10까지 합을 구하는 함수식 만들어`, `함수를 이용해서 1부터 10까지 출력해`처럼 입력합니다. 앱이 여러 의사코드 계획을 Python으로 생성하고, 각 답안의 변수 값·함수 반환값·출력과 사용한 방법을 표시합니다.

기대 출력이 같으면 직접 출력하거나 함수를 호출하는 등 여러 구현이 정답입니다. `함수를 이용해서`나 `리스트 내포를 사용해서`처럼 방법을 지정하면 해당 방법이 실제 출력이나 출력값 계산에 관여해야 합니다. **내 Python 답안 채점하기**에서도 같은 기준을 적용합니다.

변수 지정, 정수 범위 합계 함수, 문자열·정수 출력, 목록의 합계와 정렬은 제한된 Python 해석기로 실행 결과까지 채점합니다. `"안녕, 친구"를 출력해`처럼 문장을 따옴표로 감싸면 그대로 출력합니다. 방법 조건은 함수, 변수, `for`, `while`, 반복문, 리스트 내포, `sum()`, `sorted()`를 지원합니다.

### 의사코드로 프로그램 만들기

대시보드 상단에 다음처럼 의사코드를 입력하고 **Python 코드 작성**을 누릅니다.

```text
함수 배수합(목록, 기준)
    합계 ← 0
    각 값 ∈ 목록
        만약 값 % 기준 == 0
            누적 합계 ← 값
    반환 합계

출력 배수합([1, 2, 3, 4, 5, 6], 3)
```

한 줄에 한 명령을 쓰고, 블록 안에서는 공백 4칸을 더 들여씁니다. 값과 조건은 Python 표현식을 사용합니다. `반복 i = 1 .. n`의 범위에는 `n`이 포함됩니다. `FUNCTION`, `SET`, `FOR EACH ... IN ...`, `IF`, `ELSE IF`, `ELSE`, `WHILE`, `RETURN`, `PRINT`, `CALL` 같은 영어 명령도 지원합니다.

서버를 시작하면 FlyWire 모델이 80과의 의사코드 명령과 Python 구문의 관계를 학습합니다. 올바른 구문 선택에는 가상 보상 `+1`, 오답에는 `−1`을 주고, 연속 오답 뒤 정답을 고르면 최대 `+4`를 줍니다. 모델이 구문을 고르면 입력한 인자와 들여쓰기를 적용해 프로그램을 만들고 Python 문법을 검사합니다.

**예제 불러오기**에서 기존 문법과 새 문법, 사용자 예제 10개, 상세 알고리즘을 선택할 수 있습니다. 새 수업에는 목록·집합·사전 내포, 슬라이스, 언패킹, 위치 전용 인자, 키워드 전용 인자, 예외 연결, 비동기 순회와 비동기 내포가 포함됩니다. 인자가 여러 개인 명령은 `같음 결과 | a | b`처럼 구분합니다.

종합 프로그램 6개는 정답 코드의 구문 구조와 비교하며, 합쳐서 80과를 모두 사용합니다. 새 수업을 추가할 때는 `program_model.py`의 명령과 `program_checks.json` 또는 `advanced_checks.json`의 종합 평가를 갱신합니다.

### 상세 알고리즘을 Python으로 작성하기

```text
1. 새 함수 정의: gcd(a, b)
    1. 조건이 만족되는 동안: b != 0
        1. 변수 값 갱신: a, b | (b, a % b)
    2. 결과를 반환: abs(a)
```

단계 이름과 인자를 `:`으로 구분하고, 반복과 분기의 하위 단계는 들여씁니다. 조건식, 갱신할 변수, 반환값을 구체적으로 적습니다. 현재 지원 범위는 학습한 명령과 그에 가까운 표현입니다. 정수 구간 합산, 짝수 세기, 점수 등급을 나누는 절차에서 단계 표현을 학습하며, 대시보드의 **알고리즘 학습 예제**에서 볼 수 있습니다. 대시보드는 제출한 코드의 문법을 검사합니다.

단계 이름의 글자 조각과 FlyWire 활성 패턴을 함께 사용하고, 개별 학습 예문과 명령 유형별 평균을 비교합니다. 명령 유형 안팎의 글자 특징 등장 빈도를 비교해 `만약`과 `아니면 만약`처럼 비슷한 명령을 구분하는 단서를 더 반영합니다. 같은 학습 자료에서 이 점수를 빼면 학습에 없던 표현 56개 중 54개, 적용하면 56개를 맞힙니다. 이 수치는 학습한 명령 유형의 표현 변형을 다루는 프로젝트 평가입니다. [Prototypical Networks 논문](https://arxiv.org/abs/1703.05175) · [Wang과 Manning의 로그 빈도비 연구](https://aclanthology.org/P12-2018/)

생성 시 인자 형태와 분기의 위치를 검사해 문법상 사용할 수 없는 후보를 거릅니다. 평가용 상세 알고리즘 8개는 최대공약수, 이진 탐색, 삽입 정렬, 누적 합, 정렬된 목록 병합, 회문 검사, 최대 연속 부분합, 빈도 계산입니다. 생성한 함수를 준비한 경계 사례와 고정 시드로 만든 입력에 실행하고, 독립적인 정답 계산과 비교합니다. [PICARD 논문](https://aclanthology.org/2021.emnlp-main.779/) · [EvalPlus 논문](https://arxiv.org/abs/2305.01210)

### 빈칸 학습 방식

대시보드는 FlyWire 뉴런 2,048개와 방향성 연결 5,340개를 사용합니다. 예문에서 뽑은 문자 및 줄 구조 특징을 연결망에 한 번 전달하고, 평가할 때는 뉴런의 출력 패턴이 가장 비슷한 학습 예문의 보상 기록을 사용합니다. 정답은 가상 보상 `+1`, 오답은 `−1`을 받습니다. 연속 오답 1회, 2회, 3회 이상 뒤 처음 정답을 내면 각각 `+2`, `+3`, `+4`를 받습니다.

각 반복에서 지금까지 배운 모든 학습 예문을 한 번씩 다시 풉니다. 추가 복습은 연속으로 틀린 예문이 최대 5배 더 자주 뽑히게 합니다. 이 방식은 [우선순위 경험 재생 연구](https://arxiv.org/abs/1511.05952)에서 가져온 아이디어를 코드 빈칸 학습에 적용한 것입니다. 이전 과제도 계속 복습하는 설계는 [지속 학습에서의 경험 재생 연구](https://proceedings.neurips.cc/paper_files/paper/2019/hash/fa7cdfad1a5aaf8370ebeda47a1ff1c3-Abstract.html)를 참고했습니다.

## 1과 시작하기

```powershell
py -3 -X utf8 fly.py
py -3 -X utf8 fly.py --fill "speed □ 7"
```

이 명령줄 예제는 64개 뉴런으로 대입 기호 `=`부터 시작합니다. `새 예문`은 현재 문법의 학습 전후 정답 수이고, `누적`은 지금까지 배운 문법의 정답 수입니다.

```powershell
py -3 -X utf8 fly.py --through 6
```

48과에는 대입, 들여쓰기, 조건식, 반복문, 함수, 컬렉션, 예외 처리, 모듈, 데코레이터, 타입 표기, 비동기 함수, 패턴 매칭이 포함됩니다.

## 직접 가르치기

`lessons.json`에서 기존 수업의 `train`에 예문을 추가하거나, 배열 끝에 새로운 수업을 추가합니다. 각 예문에서 정답 위치를 `□` 하나로 표시하고 `token`에 빠진 기호를 적습니다. `check`에는 `train`과 다른 평가 예문을 넣습니다. 줄바꿈은 JSON에서 `\n`으로 적습니다. 예문을 바꾼 뒤에는 서버를 재시작합니다.

```json
{
  "title": "다른 반복 가능한 객체에서 값을 넘기는 yield from",
  "token": "from",
  "train": ["def draw():\n    yield □ shapes", "def rows():\n    yield □ load()"],
  "check": ["def move():\n    yield □ commands"]
}
```

연결 가중치는 원본 시냅스 수를 목적지별로 정규화해 사용합니다. 연결망은 학습 중 고정되며, 학습하는 값은 각 예문의 토큰별 보상 점수입니다.

```powershell
py -3 -X utf8 -m unittest -v
```
